好的笔记不需要复杂的格式。标题、列表、引用和代码，足以承载大部分想法。

## 标题与段落

使用二级和三级标题组织内容，右侧目录会自动收集这些标题。短段落和清晰的小标题可以让长文章更容易阅读。

### 一份简单的清单

- 用一个问题开始。
- 把过程和关键决定记下来。
- 留下下一步，而不是追求一次完成。

## 代码示例

代码块支持语法高亮，鼠标移到代码区域可以复制内容。

```bash
hugo version
hugo --minify
```

## 表格

| 内容 | 适合记录 |
| --- | --- |
| 笔记 | 一个想法、一条命令或一段过程 |
| 文档 | 可以复用的指南和参考 |
| 随笔 | 更完整的观察和思考 |
