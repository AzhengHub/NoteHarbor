NoteHarbor 是一个基于 Hugo 的文档与个人博客主题。它将清晰的内容结构与轻量的阅读体验放在一起，让你专注于写作。

## 准备环境

你需要安装 Hugo Extended 和 Node.js。克隆项目后，在项目根目录执行：

```bash
npm install
npm run serve
```

打开终端显示的地址，就可以看到示例站点。

## 写下第一篇笔记

在 `content/` 下新建一个 Markdown 文件，并添加 front matter：

```yaml
title: 我的第一篇笔记
description: 一段简短的介绍。
date: 2026-01-08
---
从这里开始，记录你想保留的东西。
```

> 不必等到想法完美才开始记录。笔记可以随着时间慢慢生长。
